# 0.3.4 — 2026-10-24

## Changed

- **`orcid_get_funding`** exposes preferred summary `putCode` values and accepts `put_code` for one deposit's own source, description, URL and exact amount/currency strings; `description_offset` continues Unicode text within both 64,000-byte surfaces, with explicit unavoidable overflow ([#76](https://github.com/cyanheads/orcid-mcp-server/issues/76)).
- **`orcid_resolve_researcher.rows`** accepts 1–10,000 and caps every search stage at 20, disclosing requested/effective sizes alongside empty-result guidance ([#77](https://github.com/cyanheads/orcid-mcp-server/issues/77)).
- **Packaging and tooling** pin Bun 1.4.4, synchronize framework guidance and audit classification, and document client-specific hosted connection settings.

## Fixed

- **ORCID response validation** rejects incompatible envelopes, consumed field types and error documents as nonretryable `invalid_upstream_response` failures instead of empty successes; valid sparse/null records and per-work bulk errors remain supported ([#75](https://github.com/cyanheads/orcid-mcp-server/issues/75)).
