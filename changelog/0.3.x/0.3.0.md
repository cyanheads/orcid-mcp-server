# 0.3.0 — 2026-09-23

## Added

- **`grant_number`** input on `orcid_search_researchers` — phrase-matches grant/award numbers on a researcher's funding items, case-insensitively over the parts between separators (#42).

## Changed

- **Blank search/resolve input is rejected at the schema, not run as a match-all.** `orcid_search_researchers` now requires at least one non-blank field — it previously fell back to `*:*` (the whole registry); `orcid_get_affiliations` rejects an explicit empty `types` array instead of silently returning no sections; `orcid_resolve_researcher` rejects a whitespace-only `name` (#34, breaking).
- **`openWorldHint: true` on the seven record-fetch tools** — they read the live ORCID Public API, not a closed local index (#38).
- **DOI/PMID inputs accept URL and label forms** — `https://doi.org/…`, `https://dx.doi.org/…`, `doi:…`, `pubmed.ncbi.nlm.nih.gov/…`, `ncbi.nlm.nih.gov/pubmed/…`, `PMID:…` — reduced to the bare identifier ORCID indexes, on both `orcid_search_researchers` and `orcid_resolve_researcher` (#44).
- **Every structured Solr clause is phrase-quoted**, DOI/PMID anchors included, so a value with inner whitespace can no longer split into extra query terms joined by a live `OR` (#47).
- **`orcid_resolve_researcher` name and institution matching is accent-insensitive** ("José" classifies the same as "Jose"), and its generic-institution-word list now covers Spanish, Portuguese, Italian, French, German, Catalan, Dutch, and the Scandinavian languages instead of English only (#35, #46).

## Dependencies
