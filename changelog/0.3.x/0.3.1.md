# 0.3.1 — 2026-09-23

## Fixed

- **`orcid_get_works` and `orcid_get_work_detail` cap each response at 64,000 bytes** (#36). A page or batch stops before it crosses the budget. `orcid_get_works` reports the cut through `truncated`/`nextOffset`, and `orcid_get_work_detail` returns the held-back put-codes in the new `deferredPutCodes` field.
- **ORCID markup in work, funding, and research-resource titles and abstracts is stripped to plain text** at the normalizer boundary (#37). Inline formatting tags such as `<i>` and `<sup>` join their neighbours, and every other tag leaves a word boundary. The deposited citation (`citation.value`) is left verbatim.
- **`orcid_get_work_detail` preserves an exhausted upstream rate limit as `RateLimited`**, forwarding `retryable`/`retryAfter` instead of downgrading it to a non-retryable `fetch_failed` (#41).
- **A repeated put-code in `orcid_get_work_detail` no longer comes back as a spurious invalid-put-code error** (#49). Duplicates are collapsed before the bulk request, so each code resolves or fails once.
