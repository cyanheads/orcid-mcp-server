# 0.3.1 — 2026-09-23

## Fixed

- **`orcid_get_works` and `orcid_get_work_detail` cap each response at 64,000 bytes** (#36). A page or batch stops before crossing the budget; `orcid_get_works` reports the cut through `truncated`/`nextOffset`, and `orcid_get_work_detail` returns held-back put-codes in the new `deferredPutCodes` field.
- **`orcid_get_work_detail` preserves an exhausted upstream rate limit as `RateLimited`**, forwarding `retryable`/`retryAfter` instead of downgrading to a non-retryable `fetch_failed` (#41).
- **A repeated put-code in `orcid_get_work_detail` no longer comes back as a spurious invalid-put-code error** — duplicates are collapsed before the bulk request, so each code resolves or fails once (#49).

## Security

- **Inline markup ORCID relays in work, funding, and research-resource titles and abstracts is stripped to plain text** at the normalizer boundary, closing an output-injection path — tags and event-handler markup no longer reach either result surface. The deposited citation (`citation.value`) is left verbatim (#37).
