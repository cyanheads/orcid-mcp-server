# 0.1.6 — 2026-05-30

## Changed

- **`orcid_search_researchers`** — `effectiveQuery` and `numFound` moved from `output` to `enrichment`; both channels (structuredContent + content[]) now receive these alongside any empty-result or pagination-overshoot guidance. `notice` likewise moved to enrichment. Removed unreachable `no_results` error contract (#6) — empty results return success with an enrichment notice.
- **`orcid_resolve_researcher`** — `queryUsed`, `relaxedQuery`, `totalFound`, and `notice` moved from `output` to `enrichment`; an `enrichmentTrailer` surfaces them in the content[] markdown trailer. Removed unreachable `no_candidates` error contract (#7) — no-match conditions return success with an enrichment notice.
- **Collection tools** (`orcid_get_works`, `orcid_get_affiliations`, `orcid_get_funding`, `orcid_get_peer_reviews`) — `notice` moved from `output` to `enrichment`; empty-result guidance now surfaces in both channels without occupying the domain return schema.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.13 → ^0.9.16
