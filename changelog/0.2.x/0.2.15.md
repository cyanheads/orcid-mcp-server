# 0.2.15 — 2026-08-24

## Fixed

- **Multi-arch Docker build** — the build stage now runs on the native build platform (`--platform=$BUILDPLATFORM`) instead of under emulation, where the `linux/amd64` leg aborted and left `0.2.14` with no published image. `ghcr.io/cyanheads/orcid-mcp-server:0.2.15` ships `linux/amd64` and `linux/arm64` again.
