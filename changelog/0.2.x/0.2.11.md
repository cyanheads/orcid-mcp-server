# 0.2.11 — 2026-07-16

## Added

- **`orcid_search_researchers`** — new `truncated` enrichment flag and optional `nextStart` output field disclose the ORCID Public API's 10,000-offset retrieval ceiling; a third notice branch explains the ceiling and recommends narrowing or partitioning the query once `numFound` exceeds it. ([#23](https://github.com/cyanheads/orcid-mcp-server/issues/23))

## Changed

- **Description accuracy** (#26) — `orcid_resolve_researcher` now states its actual candidate range (5 by default, up to 20 via `rows`) instead of "up to 5"; `orcid_get_works` and `orcid_get_work_detail` reference the real `putCode` output field instead of `put_code`; `orcid_search_researchers`'s `institutionNames` description drops the internal `expanded-search` term; the works resource description no longer names the reader. ([#26](https://github.com/cyanheads/orcid-mcp-server/issues/26))

## Fixed

- **`orcid://researcher/{orcid_id}/profile`** resource — output now includes `researcherUrls`, matching what `orcid_get_profile` already returns and what the resource's own description promises. ([#24](https://github.com/cyanheads/orcid-mcp-server/issues/24))
