# 0.2.8 — 2026-07-13

## Changed

- **`docs/design.md`** (#17) — reconciled to the current 9-tool surface: the Tools table, Domain Mapping, and Implementation Order now list `orcid_get_work_detail` and `orcid_get_research_resources`; the `Not exposed` note no longer lists `research-resources`.

## Fixed

- **`orcid_resolve_researcher` count/query pairing** (#15) — `queryUsed` and `totalFound` previously paired the primary query string with the count from a relaxed-fallback response, so a constrained primary query could be shown alongside a nonzero count that the fallback produced, not it. Both fields now always describe the same effective query — the primary query, or the final relaxed stage when a fallback ran. Two additive enrichment fields, `primaryQuery` and `primaryTotalFound`, preserve the original constrained attempt.
