# 0.2.17 — 2026-09-21

## Changed

- **A rejected tool argument carries `data.reason: "invalid_arguments"`** and ends with a `Recovery:` line — an unknown key names the keys the tool accepts, e.g. `Recovery: Unknown key bogus_key. This tool accepts: orcid_id.` (`@cyanheads/mcp-ts-core` 0.13.3, [cyanheads/mcp-ts-core#445](https://github.com/cyanheads/mcp-ts-core/issues/445)).
- **A key in another case style that names exactly one declared parameter is accepted as that parameter** (`orcidId` → `orcid_id`), and a JSON-stringified array such as `put_codes: "[9543020, 4562455]"` is repaired after the first parse fails. Any other undeclared key is still rejected, and `inputSchema` is unchanged (`@cyanheads/mcp-ts-core` 0.13.4, [cyanheads/mcp-ts-core#452](https://github.com/cyanheads/mcp-ts-core/issues/452), [cyanheads/mcp-ts-core#234](https://github.com/cyanheads/mcp-ts-core/issues/234)).
- **Tool error text closes with `(reason <reason>)`**, e.g. `(reason profile_not_found)` — this server declares no `retryable` on its contracts, so no ` · retryable`/`· not retryable` part appears. `structuredContent` is unchanged (`@cyanheads/mcp-ts-core` 0.13.5, [cyanheads/mcp-ts-core#458](https://github.com/cyanheads/mcp-ts-core/issues/458)).
- **`OrcidService` returns the framework's upstream HTTP error as-is** instead of hand-stripping `url` from its `data` — `httpErrorFromResponse` leaves the upstream URL off `error.data` by default as of `@cyanheads/mcp-ts-core` 0.13.4 ([cyanheads/mcp-ts-core#307](https://github.com/cyanheads/mcp-ts-core/issues/307)). Client errors still carry no upstream URL.
- **Server `instructions` reworded** to three sentences, same tools and workflow guidance.
- Dockerfile `HEALTHCHECK` timing aligned with the framework template (timeout 10s → 5s, start period 5s → 10s); `.env.example` comment reorganized (no behavior change); 18 framework skills and `scripts/lint-mcp.ts` synced from `@cyanheads/mcp-ts-core` 0.13.6; adds the `.github/workflows/codeql.yml` CodeQL workflow; agent docs and issue-form description text refreshed.
